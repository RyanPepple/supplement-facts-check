About

Supplement Facts Check is a one-person audit of what best-selling gut-health supplement labels disclose. It scores each label on six yes-or-no questions, publishes every score with the dated label captures it was read from, and puts all of it in the public domain.

Who runs it

Ryan Pepple. He owns CalmGut, a gut-brain axis supplement brand operating as SHUVEN, which competes with products scored here, and he runs Abovance, the consultancy that built this site. Because of the first, his own products are never ranked here: they are scored, when they have a live label, in a separate appendix by the same rubric. The full statement is on the conflict-of-interest page.

Find him on LinkedIn and on GitHub, where this project lives.

How the scoring works

The six criteria were committed to public version control before any product was scored, so the rubric could not be tuned to a result. Each label is read from a screenshot of the live listing on a stated date. A score describes what the label discloses. Nothing is lab-tested, no claim is made about whether a product works, and nothing here is medical advice. The methodology has every rule and every ruling.

Corrections

If a score, a transcribed ingredient line or a dose reference is wrong, open an issue on the repository with the page and what the label shows. Brands are welcome to do the same, including to point to a certificate of analysis the search missed. A correction changes the data file, the site is rebuilt from it, and the change is visible in the public commit history, which is this site's corrections log. Methodology changes are listed in the revision history of the README.

Reusing the data

Every score, capture and reference row is public domain under CC0 1.0. No permission is needed. A link back is appreciated, and each headline finding has a sentence written to be quoted.
